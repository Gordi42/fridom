upwind5 storage-shape regression — raw GPU results
single A100-SXM4-80GB, Levante, jax/jaxlib 0.10.2 (cuda12 plugin),
float64, nsys 2026.1.3, ncu 2026.1 (cuda-13.3 module). Fresh process per
variant; clocks pinned 1410 MHz SM / 1593 MHz mem, GPU cool (43-49 C),
dedicated (no foreign compute-app) throughout. 2026-07-18.

Harness: rep_step.py (per-rep step ms, one variant/process, first advance
excluded); prof_step.py (cudaProfilerApi region for nsys); nsys via
run_nsys.sh with --cuda-graph-trace=node (see METHOD NOTE below).
Widths forced with the floor_halo monkeypatch on the two negotiation
seams (biased upwind5 natural = width 3 -> 198^3; wide = width 4 ->
200^3; wN,N,N = uniform per-axis width N -> (192+2N)^3).

6. SCHEME-DEPENDENCE — centered advection storage sweep at 192^3 (2 procs each)
   the "lucky" shape MOVES with the scheme -> confirms no universal rule
============================================================

centered 198^3 (w3)          : med 3.393 / 3.390   +11%
centered 200^3 (w4)          : med 3.219 / 3.221   +5%   (200 is NOT best here)
centered 202^3 (w5)          : med 3.534 / 3.540   +15%
centered 208^3 (w8)          : med 3.511 / 3.531   +15%
  196 = 2^2*7^2 (2^6*7^6 cube). upwind5 best = 200^3; centered best = 196^3.
  Implication for the centered n+4->n+2 gate: current centered storage is
  196^3 (FAST); the narrowing target 194^3 (=2*97, hostile factorization like
  198/202) will very likely REGRESS at 192^3, mirroring upwind5 n+8->n+6.

============================================================
7. INSTABILITY — did NOT reproduce on a dedicated cool GPU
============================================================
All runs above are stable to +/-0.02 ms across processes and reps; SM clock
pinned at 1410 MHz throughout (logged before/after every process). autotune=0
gives byte-identical medians -> not autotune nondeterminism. The predecessor's
16% cross-process wobble (storage_halo_gpu_ab.md) coincided with a foreign
~65 GiB spike.py sharing the device; the memory-inefficient 198^3 shape (sec 4)
is the more DRAM-contention-sensitive of the pair, so a shared GPU amplifies
its variance. On a dedicated GPU the slow shape is DETERMINISTICALLY slow.
